## Recent builds

### 📍 Pinned — native iOS app for saving places
SwiftUI, SwiftData, MapKit, private CloudKit sync. No servers, no tracking. Live on the App Store.
- https://critchlow.us/pinned

### ☀️ Helio — minimalist solar activity visualizer
Live NOAA data rendered as a pixel-grid sun, with sunspot regions at real heliographic coordinates and a 28-day scrubber to replay the month.
- Repo: https://github.com/DomCritchlow/helio

### 📡 Airwave ML — PyTorch models for radio/audio decoding
Sequence models (CTC + attention variants) with reproducible training workflows and dataset tooling.
- Repo: https://github.com/DomCritchlow/airwave-ml

### 🎙️ Vibecast — daily automated podcast pipeline
GitHub Actions pipeline: source gathering → script generation → TTS → podcast feed. Runs unattended daily.
- Repo: https://github.com/DomCritchlow/vibecast

### 📻 HamOps — amateur radio API service
FastAPI service for callsign lookup, APRS tracking, and band planning. Built agent-friendly (MCP).
- Repo: https://github.com/DomCritchlow/hamops
